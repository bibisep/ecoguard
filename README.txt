## 📖 Sobre o projeto

O **ECOGUARD** é um protótipo de aplicativo desenvolvido para facilitar o acesso a informações ambientais e incentivar a prevenção de riscos climáticos.

A proposta é reunir, em uma interface intuitiva e acessível, informações sobre condições ambientais, alertas preventivos e orientações que contribuam para a segurança e o bem-estar da população.

O projeto foi desenvolvido no contexto acadêmico da **FIAP**, explorando tecnologias web e conceitos de inteligência climática, sustentabilidade e experiência do usuário.

---

## 🎯 Problema

Eventos climáticos extremos, como ondas de calor, chuvas intensas e episódios de baixa qualidade do ar, podem afetar diretamente a saúde, a mobilidade e a qualidade de vida da população.

Entretanto, informações sobre esses riscos nem sempre são apresentadas de maneira centralizada, simples e acessível.

O ECOGUARD surge como uma proposta para aproximar a população das informações ambientais e estimular atitudes preventivas.

---

## 💡 Nossa solução

O ECOGUARD propõe uma plataforma digital capaz de apresentar condições ambientais, identificar visualmente diferentes níveis de risco e disponibilizar recomendações preventivas.

A aplicação utiliza uma abordagem visual e interativa para tornar a interpretação dos dados mais simples, permitindo que o usuário compreenda possíveis situações de risco em sua região.

---

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| 🏠 Dashboard ambiental | Visão geral das condições ambientais e dos alertas recentes. |
| 🌡️ Indicadores climáticos | Exibição de informações como temperatura e qualidade do ar. |
| 🚨 Alertas ambientais | Apresentação de riscos relacionados a calor extremo, chuvas intensas e qualidade do ar. |
| 📋 Detalhes dos alertas | Informações sobre níveis de risco, possíveis impactos e cuidados recomendados. |
| 🗺️ Mapa interativo | Visualização geográfica de pontos de atenção e indicadores de risco. |
| 🔔 Notificações demonstrativas | Simulação visual de alertas preventivos. |
| 👤 Perfil e preferências | Interface para visualização e configuração de preferências do usuário. |
| 📱 PWA | Possibilidade de adicionar o aplicativo à tela inicial de dispositivos compatíveis. |
| 💻 Layout responsivo | Adaptação da interface para celulares, tablets e computadores. |

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido com as seguintes tecnologias:

- **HTML5:** estrutura e organização das interfaces.
- **CSS3:** estilização, animações e responsividade.
- **JavaScript:** interatividade e lógica de navegação.
- **Leaflet.js:** implementação do mapa interativo.
- **Progressive Web App (PWA):** experiência de aplicativo instalável.
- **Web App Manifest:** configuração de nome, ícones e apresentação do aplicativo.
- **Service Worker:** gerenciamento de cache e suporte a recursos offline.
- **Git e GitHub:** versionamento e colaboração.
- **GitHub Pages:** hospedagem da aplicação.

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/bibisep/ecoguard.git
```

### 2. Acesse a pasta

```bash
cd ecoguard
```

### 3. Execute o projeto

Abra a pasta no Visual Studio Code e utilize uma extensão de servidor local, como o **Live Server**, para visualizar a aplicação no navegador.

O projeto também está disponível online:

**https://bibisep.github.io/ecoguard/**

---

## 📲 Como instalar o ECOGUARD

O ECOGUARD utiliza a tecnologia **Progressive Web App (PWA)**, permitindo uma experiência semelhante à de um aplicativo nativo.

### iPhone (Safari)

1. Abra o endereço do ECOGUARD no Safari.
2. Toque no botão de compartilhamento.
3. Selecione **Adicionar à Tela de Início**.
4. Confirme a adição.

### Android (Chrome)

1. Abra o endereço do ECOGUARD no Chrome.
2. Acesse o menu do navegador.
3. Selecione **Instalar app** ou **Adicionar à tela inicial**, conforme a opção disponível.
4. Confirme.

> A instalação e os recursos disponíveis podem variar conforme o navegador e o sistema operacional.

## 🌱 Impacto e sustentabilidade

O ECOGUARD busca contribuir para:

- Democratização do acesso à informação ambiental.
- Conscientização sobre riscos climáticos.
- Incentivo à prevenção e ao autocuidado.
- Promoção de comunidades mais informadas.
- Aplicação da tecnologia em desafios socioambientais.

O projeto dialoga com os Objetivos de Desenvolvimento Sustentável (ODS) da Organização das Nações Unidas, especialmente:

**ODS 3:** Saúde e Bem-Estar.

**ODS 11:** Cidades e Comunidades Sustentáveis.

**ODS 13:** Ação Contra a Mudança Global do Clima.

## ⚠️ Aviso importante

O ECOGUARD é um **protótipo acadêmico**, desenvolvido para fins educacionais e demonstrativos.

As informações, indicadores e notificações apresentados na versão atual não devem ser interpretados como alertas oficiais ou monitoramento ambiental em tempo real.

Em situações de emergência, consulte os canais oficiais da Defesa Civil e dos órgãos competentes.
