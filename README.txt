ECOGUARD - MVP de demonstração

1. Abra index.html em um navegador (Chrome, Edge ou Safari).
2. Clique em Começar e siga as telas.
3. Na tela principal, clique em Atenção ao calor para ver os detalhes.
4. Use o botão Simular notificação para abrir a tela de bloqueio e toque no aviso.
5. Para testar no celular, publique index.html no GitHub Pages ou execute um servidor local acessível na rede.

IMPORTANTE: Todos os valores de clima e alertas são fictícios. O projeto não envia notificações push reais, não acessa dados climáticos em tempo real e ainda não é um PWA instalável. O logo é provisório.
